# 🏫 Campus AI - Issue Detection & Image Captioning

This project provides an AI pipeline combining **YOLO11**, **Hugging Face CLIP**, and **Salesforce BLIP** to detect campus issues (garbage, water stagnation, crowds, overgrown plants, water leakage, dirty bathrooms) and generate natural-language descriptions.

## 🚀 Running Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
